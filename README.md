# Investment Calculator

A comprehensive investment comparison tool built with React.

## Features

- Compare rental property, infrastructure bonds, and fixed deposits
- Customizable input parameters
- Real-time calculations and visualizations
- Year-by-year profit analysis
- Break-even analysis
- CSV export functionality

## Getting Started

### Prerequisites

- Node.js 14 or higher
- npm or yarn

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Open your browser to `http://localhost:5173`

### Building for Production

```bash
npm run build
```

The production files will be in the `dist` directory.

## Usage

1. Adjust input parameters in the collapsible "Input Parameters" section
2. View different chart perspectives using the view toggle buttons
3. Examine detailed year-by-year data in the table
4. Export results to CSV for further analysis

## Technology Stack

- React 18
- Recharts for data visualization
- Tailwind CSS for styling
- Lucide React for icons
- Vite for build tooling
